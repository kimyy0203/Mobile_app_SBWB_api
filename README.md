# 🔌 소방와방 - Backend API Specification

> **2025년 항공소프트웨어프로젝트 '소방와방' 앱**
> 공공데이터 포털 및 Kakao Maps API를 연동하고, 사용자 인증(JWT) 및 실시간 현장 정보(마커/코멘트) 공유를 처리하는 백엔드 API 명세서 및 아키텍처 요약입니다.

---

## 🛠️ 1. 백엔드 기술 스택 (Tech Stack)

* **Framework**: Java (Spring Boot)
* **Database**: MariaDB
* **Infrastructure**: NAVER CLOUD PLATFORM (NCP)
* **Authentication**: JWT (JSON Web Token)
* **API Integration**: 공공데이터포털 소방 장비 API, Kakao Maps API

---

## 📐 2. 시스템 구성 및 데이터 흐름 (Data Flow)

소방와방 앱의 백엔드는 클라이언트(Flutter)의 요청을 받아 비즈니스 로직을 처리하고, 외부 공공데이터와 자체 MariaDB의 데이터를 가공하여 안전하게 전달합니다.

1. **외부 API 연동**: 공공데이터 포털에서 소방용수 및 소방 장비의 위도·경도 좌표 데이터를 실시간 또는 배치로 호출합니다.
2. **자체 데이터 적재**: 사용자가 현장에서 등록하는 새로운 위험 구역 마커와 실시간 코멘트 정보는 NCP에 구축된 MariaDB에 안전하게 저장·관리됩니다.
3. **인증 및 보안**: 모든 데이터 요청은 Spring Boot 서버에서 **JWT 토큰** 검증을 거친 후 권한이 있는 사용자(소방공무원 등)에게만 응답을 반환합니다.

---

## 📑 3. 핵심 API 기능 명세 (API Functions)

### 👤 3-1. 인증 및 회원 관리 (Authentication)
* **POST /api/auth/signup (회원가입)**
  * 사용자 계정(ID, 비밀번호, 이름, 연락처 등)을 생성합니다. 예외적인 입력 형태가 들어올 경우 서버 단에서 검증 후 에러 메시지를 반환합니다.
* **POST /api/auth/login (로그인 및 토큰 발급)**
  * 계정 정보가 일치하면 서버에서 보안 검증을 완료한 후, 클라이언트에 **JWT 토큰**을 전달합니다. 이후 클라이언트는 모든 요청 헤더에 이 토큰을 포함하여 인증을 대행합니다.
* **PUT /api/user/profile (프로필 및 관할 구역 수정)**
  * 사용자의 비밀번호 변경 및 소속된 관할 구역 정보를 업데이트합니다.

### 📍 3-2. 지도 마커 및 오버레이 (Map & Markers)
* **GET /api/markers (주변 장비 및 위험 지역 조회)**
  * 사용자의 GPS 좌표(위도, 경도) 또는 행정구역 필터 조건을 기반으로 공공 데이터 및 자체 등록 마커 리스트를 반환합니다. Kakao Maps 오버레이 레이어에 렌더링됩니다.
* **POST /api/markers (신규 마커 생성)**
  * 사용자가 지도 상에서 직접 지정한 좌표에 위험물, 통행 제한 구역 등의 카테고리를 선택하고 코멘트를 작성하여 새로운 마커를 등록합니다.

### 💬 3-3. 코멘트 및 게시판 (Comments & ChatPage)
* **GET /api/comments/{markerId} (마커 상세 코멘트 조회)**
  * 특정 마커에 누적된 소방관들의 현장 경험 및 장비 상태(ex. "해당 소화전 동파로 사용 불가", "좁은 도로로 대형 펌프차 진입 불가") 코멘트를 실시간으로 가져옵니다.
* **POST/PUT/DELETE /api/comments (코멘트 C.R.U.D)**
  * 현장 상황 변동에 따라 다른 사용자들도 코멘트를 추가, 수정, 삭제할 수 있도록 처리하여 데이터의 실시간 동기화를 지원합니다.
* **GET /api/chat/search (통합 검색 및 필터링)**
  * 게시판(채팅) 페이지에서 특정 키워드나 지역 필터링을 통해 등록된 코멘트를 검색하고, 해당 데이터가 위치한 지도의 핀 좌표로 바로 이동할 수 있도록 데이터를 맵핑해 줍니다.
